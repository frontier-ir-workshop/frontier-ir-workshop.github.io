# AAAI 2027 Workshop on New Frontiers in Information Retrieval

This repository hosts the website for the Second Workshop on New Frontiers in Information Retrieval (FrontierIR), held at AAAI 2027 in Montréal, Canada.

The website of the first edition (AAAI 2026, Singapore) is preserved under [`2026/`](2026/) and linked from the main page.

## About

Information retrieval (IR) is becoming a core capability of modern AI systems, extending beyond document ranking to support complex instructions, reasoning, and action. The workshop brings together researchers and practitioners from IR, natural language processing, multimodal learning, software engineering, robotics, and agentic AI, with particular emphasis on retrieving memories, tools, skills, code, and environmental context for agents and embodied systems.

## Updating the site

- `index.html` is the current (2027) page; `assets/` holds shared CSS/JS/images.
- Accepted papers are loaded from `accepted_papers.csv` in the repository root (same column layout as `2026/accepted_papers.csv`); the "Accepted Papers" section shows a placeholder until that file exists.
- People without a photo use `assets/img/placeholder.png`; drop a photo into `assets/img/speakers/` or `assets/img/organizers/` and update the `<img>` tag.
